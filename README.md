# My portfolio

A Next.js portfolio with source-controlled content and statically generated project pages. It has no database, admin CMS, or server-side API.

## Run locally

```sh
npm install
npm run dev
```

Check the production build with `npm run build`, then preview it with `npm start`.

## Deploy to Vercel

Import this repository into Vercel and use the detected Next.js settings. No database or credentials are required. See [VERCEL_DEPLOYMENT.md](./VERCEL_DEPLOYMENT.md) for deployment and content-update details.
